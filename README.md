# Cervical Cancer Prediction using Machine Learning

## 📌 Project Overview

Cervical cancer is one of the major health concerns affecting women worldwide. Early prediction and identification can help in timely diagnosis and treatment.

This project focuses on developing a machine learning-based system for predicting cervical cancer risk using patient-related risk factors.

## 🎯 Objectives

* Predict cervical cancer risk using machine learning techniques.
* Identify important risk factors associated with cervical cancer.
* Apply feature selection to improve model performance.
* Compare multiple machine learning classification algorithms.
* Evaluate the models using different performance metrics.

## 📊 Dataset

The project uses the Cervical Cancer Risk Factors Dataset from the UCI Machine Learning Repository.

The dataset contains patient-related risk factors and a binary target indicating cervical cancer diagnosis.

## 🤖 Machine Learning Algorithms

The following machine learning algorithms were evaluated:

* Logistic Regression
* Support Vector Machine (SVM)
* Decision Tree
* Random Forest
* K-Nearest Neighbors (KNN)
* Gaussian Naive Bayes
* AdaBoost
* XGBoost

## 🔍 Feature Selection

Particle Swarm Optimization (PSO) was used for feature selection.

Important selected features include factors such as:

* Age
* Number of Pregnancies
* Age at First Sexual Intercourse
* Smoking-related factors
* STD-related factors

## ⚙️ Methodology

The project follows these major steps:

1. Data Collection
2. Data Preprocessing
3. Handling Missing Values
4. Handling Class Imbalance
5. Feature Scaling
6. Feature Selection using PSO
7. Model Training
8. Hyperparameter Tuning
9. Model Evaluation
10. Performance Comparison

## 📈 Evaluation Metrics

The models were evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Matthews Correlation Coefficient (MCC)

## 🏆 Results

The proposed machine learning approach achieved approximately **94% accuracy** in the experimental evaluation.
